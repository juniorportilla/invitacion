# Invitación para Facebook

Esta carpeta está preparada para publicarse gratis con GitHub Pages.

## 1. Crea un repositorio
En GitHub crea un repositorio público llamado:

invitacion

## 2. Sube estos dos archivos
- index.html
- invitacion.png

## 3. Activa GitHub Pages
En el repositorio:
Settings → Pages → Deploy from a branch → main → /(root) → Save

La dirección quedará aproximadamente así:

https://TU_USUARIO.github.io/invitacion/

## 4. MUY IMPORTANTE
Abre index.html y reemplaza todas las apariciones de:

TU_USUARIO

por tu nombre de usuario de GitHub.

Ejemplo:
https://juan123.github.io/invitacion/

## 5. Comparte ESA dirección en Facebook
No compartas el pin.it directamente. Comparte:

https://TU_USUARIO.github.io/invitacion/

Facebook podrá leer los datos Open Graph de la página y usar la imagen de invitacion.png para la vista previa.

El botón y la redirección llevan a:
https://pin.it/6Ua5oeDLo
